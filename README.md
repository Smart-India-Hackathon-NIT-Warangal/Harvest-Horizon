
#  HarvestHorizon: Your Farm, Smarter  

Welcome to the official repository for **HarvestHorizon**, an **AI-powered platform** designed to revolutionize agriculture.  
This project was developed by **Team HackHorizon** from the *National Institute of Technology, Warangal* for the **Smart India Hackathon**.  

>  Our mission is to empower farmers with predictive analytics to make informed decisions, increase crop yield, reduce waste, and grow with confidence.  

---

##  How It Works  

HarvestHorizon leverages **machine learning** to provide two core services:  

- **Crop Recommendation** – Suggests the most suitable crops based on soil and climate conditions.  
- **Yield Prediction** – Forecasts potential harvest with cost-effective optimization.  

🔹 **Data-Driven Insights:**  
The system collects and analyzes crucial data including:  
- Historical crop data  
- Soil health metrics (Nitrogen, Phosphorus, Potassium levels)  
- Real-time weather information  

🔹 **Powerful Machine Learning Models:**  
- **Crop Recommendation:** Support Vector Machine (SVM)  
- **Yield Prediction:** XGBoost & Histogram-based Gradient Boosting  

🔹 **Actionable Recommendations:**  
- Approximate yield predictions  
- Economic strategies to maximize output and minimize input costs  

🔹 **User-Friendly Interface:**  
- Accessible, multilingual web interface designed with farmers in mind
